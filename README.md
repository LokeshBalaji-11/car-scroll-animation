## 📖 Objective
This project is a frontend assignment focused on creating a high-quality, scroll-driven hero section. The core animation is tied directly to the user's scroll progress (not time-based autoplay), ensuring a smooth, fluid, and premium interaction. 

## 💻 Tech Stack
* **Framework:** Next.js (React)
* **Styling:** Tailwind CSS (featuring custom neon gradients and glassmorphism UI)
* **Animation:** GSAP & ScrollTrigger

## ✨ Features
* **Initial Load Animation:** The headline and stats fade in smoothly with a staggered reveal.
* **Scroll-Based Interaction:** The car moves left-to-right based strictly on the scrollbar's progress.
* **Dynamic Trail:** A glowing neon trail scales dynamically behind the car as it moves.
* **Responsive Design:** Ensures the animation remains consistent across standard display sizes.
